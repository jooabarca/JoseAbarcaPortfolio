> sample query // fictional schema, same idea

-- LYBUNT: gave Last Year But Unfortunately Not This year
WITH yearly AS (
  SELECT donor_id,
         YEAR(gift_date)  AS gift_year,
         SUM(amount)       AS total
  FROM   dbo.gifts
  GROUP BY donor_id, YEAR(gift_date)
)
SELECT   ly.donor_id, ly.total AS last_year_total
FROM     yearly ly
LEFT JOIN yearly ty
       ON ty.donor_id = ly.donor_id
      AND ty.gift_year = ly.gift_year + 1
WHERE    ly.gift_year = YEAR(GETDATE()) - 1
  AND    ty.donor_id IS NULL
ORDER BY ly.total DESC;

C Tender radar

Chile's public institutions buy through Mercado Público, the state procurement platform. Paid platforms sell tender alerts as a monthly subscription; this one is built into the ERP and tuned to exactly what Hagotek installs. Every morning a GitHub Actions job pulls the open tenders, scores the ones it hasn't seen yet and keeps the relevant ones. Unlike the rest of the ERP, this module only works with public data, so it gets a real screenshot:

> how it decides

  • Weighted keyword rules for five categories (audio, audiovisual, CCTV / security, access control, automation); a match in the title or description weighs more than one buried in the item list
  • The UNSPSC product codes of each item add to the score
  • Filters out tenders that only match by shared words (security guards, medical hearing aids…) and one-off event rentals
  • Flags the ones that include on-site installation, not just shipping boxes
  • Keeps tracking saved tenders after they close, to see whether they were awarded or declared void
  • Emails a morning digest of the new matches through Resend, with HTML built to render in Outlook
  • In the ERP: open / following / discarded views, category and installation filters, search, and a status for each tender from New to Bidding to Won or Lost
  • Deliberately simple: hand-tuned rules refined by checking what gets in and what doesn't, not a model

MI ASISTENTE

REAL-TIME VOICE AI COMPANION · LANGUAGE COACH · WINDOWS · ANDROID

A desktop voice assistant I talk to through my earbuds. It streams audio to the Gemini Live API (or the OpenAI Realtime API) over WebSockets, answers in a natural voice and can be interrupted mid-sentence. Its listener modes stay silent during meetings and only whisper a correction when someone says something false, a neutral counterpoint to sweeping opinions, or a useful fact, checking Wikipedia before correcting.

It's also the perfect partner to learn English, Spanish, Portuguese or Japanese: it talks with you in the language, corrects your mistakes on the spot and saves them so you can review them later.
